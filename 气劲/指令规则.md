# 茗伊团队气劲面板指令

> **版本要求**：需要版本 ≥ 4.71。旧版本仅支持分析玩家技能与吃鸡地图。

| 命令 | 参数 | 帮助 |
| --- | --- | --- |
| `/szName` | 1个，字符串 | 指定气劲自定义名称，如 `/szName 减伤·春泥护花`，将气劲显示名称修改为 `减伤·春泥护花` |
| `/nIcon` | 1个，整数型 | 指定气劲自定义图标，如 `/nIcon 112`，将气劲图标自定义为112号图标 |
| `/MapID` | 无限，整数型，用逗号分割 | 指定气劲生效地图，如 `/MapID -1,2`，将气劲生效地图设置为 通用地图（-1），万花地图（2） |
| `/nLevel` | 1个，整数型 | 指定气劲等级，如 `/nScrutinyType 2`，气劲等级为3，但不会勾选区分等级 |
| `/nCount` | 1个，整数型 | 指定气劲生效层数，如 `/nCount 2`，气劲层数至少为2层才会触发 |
| `/nScrutinyType` | 1个，整数型 | 指定气劲监控对象，1自身，2团队，3敌对，4当前目标，如 `/nScrutinyType 1`，气劲在自身生效才会触发 |
| `/tKungFu` | 无限，字符串，用逗号分割 | 指定气劲生效心法，如 `/tKungFu ["SKILL#10002"]=true,["SKILL#10003"]=true,"`，洗髓经，易筋经，心法下生效 |
| `/tMark` | 10个，字符串，用逗号分割 | 指定气劲获得后标记，如 `/tMark true,false,false,false,false,false,false,false,false,false`，获得气劲后标记为白云 |
| `/disableTeamPanel` | 0个 | 指定气劲禁用团队面板，如 `/disableTeamPanel`，此气劲不生效团队面板 |
| `/bCenterAlarm1` | 0个 | 指定气劲获得后中央警报，如 `/bCenterAlarm1` |
| `/bCenterAlarm2` | 0个 | 指定气劲失去后中央警报，如 `/bCenterAlarm2` |
| `/bPartyBuffList1` | 0个 | 指定气劲获得后团队气劲列表，如 `/bPartyBuffList1`，获得气劲后显示团队气劲列表 |
| `/bBuffList1` | 0个 | 指定气劲获得后自身气劲列表 |
| `/szVoice1` | 1个，字符串 | 指定气劲获得后播放语音，如 `/szVoice1 ZhuanHuo_T_BY`，获得气劲后播放 转火白云 |
| `/szVoice2` | 1个，字符串 | 指定气劲失去后播放语音，如 `/szVoice1 ZhuanHuo_T_BY`，失去气劲后播放 转火白云 |
| `/bVoiceSelfOnly1` | 0个 | 指定气劲获得后是否仅在自身气劲下播放语音 |
| `/bVoiceSelfOnly2` | 0个 | 指定气劲失去后是否仅在自身气劲下播放语音 |
| `/bTeamChannel1` | 0个 | 指定气劲获得后团队频道报警 |
| `/bTeamChannel2` | 0个 | 指定气劲失去后团队频道报警 |
| `/bWhisperChannel1` | 0个 | 指定气劲获得后密聊频道报警 |
| `/bWhisperChannel2` | 0个 | 指定气劲失去后密聊频道报警 |
| `/reservedEx` | 1个 | 4.82新增。保留扩展，字符串直接拼接至原始数据 |
| `/shield` | 0个 | 4.91优化。指定气劲在秘境地图不开启头顶染色，该指令只在气劲开启头顶警报功能且生效地图包含id为-1通用地图时有效 |
| `/Reshield` | 0个 | 4.91新增。与（`/shield`）指令相反，若该气劲在秘境地图屏蔽了头顶警报功能，则取消屏蔽，在秘境地图仍允许头顶染色 |
| `/bTeamPanel1` | 1个，整数型 | 5.11新增。2026.10.11修改为 `/bTeamPanel1`。参数为0则关闭仅显示来源自己的气劲（bOnlySelfSrc），大于0则开启。该指令指定气劲获得后团队面板，注：此指令操作的是动态事件的团队面板，而非条件团队面板，优点是可以设置监控对象（全部，自己）或是自身心法，缺点是无法设置备注文字与优先级 |
| `/bFullScreen1` | 0个 | 5.11新增。2026.10.11修改为 `/bFullScreen1`。指定气劲获得后全屏泛光报警。 |
| `/col` | 3个，整数型，用逗号分割 | 2025.08.26新增。强制指定气劲通用颜色col的rgb值。例如 `"255,204,32,"` 最好尾部额外带一个逗号，防止Excel将其当做数值而非文本 |
| `/bScreenHead1` | 0个 | 2026.10.11新增。指定获得气劲开启头顶警报 |
| `/bVoiceOfficial1` | 0个 | 2026.10.11新增。指定获得气劲优先使用官方语音条目 |
| `/bVoiceOfficial2` | 0个 | 2026.10.11新增。指定失去气劲优先使用官方语音条目 |
